Name of Quantlet: IGARCH11_Rugarch_Example

Published in: Econometrics_R

Description: This R script specifies and estimates an IGARCH(1,1) model using the rugarch package. It follows the manuscript example by constructing an iGARCH variance specification with a constant mean equation and normal innovations, fitting the model to a univariate return series called data. To make the script directly runnable, it simulates a simple return series when data is not already present in the workspace, then prints the fitted model output.
