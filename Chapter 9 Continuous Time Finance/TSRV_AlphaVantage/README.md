# Two-scale realised variance

The example now uses the fixed public `highfrequency` sample in
[Intraday_Fixed_Sample](../Intraday_Fixed_Sample). No API key or market-data
subscription is required. The earlier folder name is retained so existing
book links continue to work.

Run `Rscript tsrv_alpha_vantage.R` from this folder, or open the linked folder
for the full script, data, documentation and expected output.
